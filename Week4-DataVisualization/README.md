# 📊 Sales Data Visualization

A data analysis project that cleans, explores, and visualizes retail sales data to uncover trends across regions, products, and time.

This project was built as part of a Data Science internship (Week 4 task) and demonstrates an end-to-end exploratory data analysis (EDA) workflow — from raw CSV data to publication-ready charts.

## 📌 Project Overview

The notebook performs the following steps:

1. **Data Loading** — Reads sales data (`Date`, `Region`, `Product`, `Quantity`, `Price`, `Total_Sales`) from a CSV file.
2. **Data Cleaning**
   - Checks and removes missing values
   - Converts the `Date` column to a proper datetime format
   - Ensures numeric columns (`Quantity`, `Total_Sales`) are correctly typed
3. **Exploratory Analysis**
   - Generates summary statistics (mean, std, min/max, etc.)
   - Aggregates total sales by **Region**
   - Aggregates total sales by **Product**
4. **Visualization**
   - Bar chart: Total Sales by Region
   - Bar chart: Total Sales by Product
   - Line chart: Daily Sales Trend Over Time

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Add your data
Place your `sales_data.csv` file inside the `data/` folder. Expected columns:

| Column        | Description                     |
|---------------|----------------------------------|
| `Date`        | Date of the transaction          |
| `Region`      | Sales region                     |
| `Product`     | Product name                     |
| `Quantity`    | Units sold                       |
| `Price`       | Unit price                       |
| `Total_Sales` | Total revenue for the transaction |

### 4. Run the analysis
Using the notebook:
```bash
jupyter notebook analysis.ipynb
```
Or as a script:
```bash
python main.py
```
